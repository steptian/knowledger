# knowledger 快速上手：安装 + 日常使用

> knowledger 是通用工具：装上它，用 `knowledger init` 建你自己的知识库。全文命令 2026-11-24 实测（macOS / Python 3.13 / 干净 venv）。

## 一、安装（5 分钟）

| # | 做什么 | 验证 |
|---|---|---|
| 1 | Python ≥ 3.10 | `python3 --version` |
| 2 | 装 knowledger（见下） | `knowledger --version` |
| 3 | 建你自己的库并自检 | `knowledger init my-kb && cd my-kb && knowledger selftest` |

**装法**（PyPI 未发布，目前从源码装）：

```bash
python3 -m venv ~/venvs/kb
~/venvs/kb/bin/pip install /path/to/knowledger源码目录            # 约 5 秒，核心零第三方依赖
# 要接 WorkBuddy / 豆包 / Claude（MCP）再补一句：
~/venvs/kb/bin/pip install '/path/to/knowledger源码目录[mcp]' -i https://mirrors.aliyun.com/pypi/simple/
```

- 安装那一下需要外网（pip 拉构建工具）；装完，核心运行零第三方依赖。
- mcp extra 已锁 `mcp>=1.0,<2`：SDK 2.x 改了 API（`tools/call` 会静默失败），别升 2.x。
- Windows 未实测；控制台中文乱码先 `set PYTHONIOENCODING=utf-8`。

## 二、建库（一次性，10 分钟）

```bash
knowledger init my-kb && cd my-kb
$EDITOR knowledger.yaml    # 唯一配置：块、owners、类型、关系词表——照模板改
knowledger selftest        # init 自带的故意违规样例必须被拦
knowledger scan ~/你的文档目录
knowledger cards           # 每份文档一张索引卡 → staging/
knowledger open            # 浏览器待办总览：待认领 / 需 OCR / 待审边——日常从这里开始
```

**团队协作是可选的**：knowledger.yaml 里给每个块填真名 owner，审核就按这张表卡权限；数据目录整个放进你们自己的 git 仓（PR 即审批留痕），多人协作靠它。一个团队一个仓，互不相干。

## 三、日常动线（审核的人）

```bash
knowledger open            # 待办总览——从这开始
knowledger claim D-XX --by 你的名字              # 认领一张 staging 卡：写 owner、归位 blocks/
knowledger review edges    # 待审边，每条带两端定义 + 源文出现行
knowledger approve D-XX contains BF-01 ok --by 你的名字 "备注"   # 审一条边
knowledger check && knowledger build                  # 过关 + 重新编译 AI 快照
knowledger drift           # 每周跑：哪些源文档变了 → 待重审
```

也可以把页面右侧「交给 Agent」框里的指令贴给 WorkBuddy / 豆包 / 任意能跑 shell 的 Agent：它把证据念给你听、问你、替你执行。它自编名字会被拒绝——必须以该块 owner 的名义。

**接 AI 客户端**：

```json
{ "mcpServers": { "knowledger": { "command": "<knowledger 可执行文件绝对路径>", "args": ["serve"], "cwd": "<你的知识库目录绝对路径>" } } }
```

## 四、常见问题

| 现象 | 原因 / 处理 |
|---|---|
| approve / claim 被拒「不是 owner」 | 名字必须与 knowledger.yaml 该块 owners 完全一致；不一致找管理员改配置 |
| 某个块谁都不能写 | 该块 `owners: null`——先定责任人，再改 knowledger.yaml |
| `knowledger open` 提示先 build | 快照没编译：先 `knowledger build` |
| serve 报 mcp 不可用 | 需要 1.x：`pip install 'mcp<2'` |
| doc / docx / pdf 的卡没有候选条目 | 二进制未抽正文：docx 旁车 .md（待做）；doc / pdf 先 OCR 再重跑 cards |
